# 🎬 YouTube Shorts: Автопрокрутка и Голосовое управление

Браузерное расширение (Chrome / Chromium Manifest V3), которое автоматически перелистывает YouTube Shorts после окончания видео, а также позволяет управлять воспроизведением и пропускать неинтересные видео **голосом** (например, сказав *"далее"* или *"пропустить"*).

---

## ✨ Основные возможности

1. **🔄 Автоматическая прокрутка (Auto-Scroll):**
   - Отслеживает окончание видео в YouTube Shorts.
   - Корректно работает как с обычным завершением, так и с встроенным циклом зацикливания Shorts (loop).
   - Настраиваемая задержка перед переключением (0 сек, 0.5 сек, 1 сек, 2 сек).
   - Если вы поставили видео на паузу вручную — автопрокрутка ждет вас и не переключает видео.
   - Визуальная полоса прогресса до момента переключения.

2. **🎙️ Голосовое управление (Voice Control):**
   - Распознавание в реальном времени через Web Speech API (работает локально в браузере).
   - **Пропуск видео:** просто скажите *"далее"*, *"дальше"*, *"пропустить"*, *"скип"* или *"не понравилось"*.
   - **Предыдущее видео:** скажите *"назад"* или *"обратно"*.
   - **Пауза / Плей:** скажите *"пауза"* или *"плей"*.
   - **Лайк:** скажите *"лайк"* или *"нравится"*.
   - **Заново:** скажите *"заново"* или *"повтор"*.
   - Поддерживает русский и английский языки.
   - Полностью бесшумный режим: никаких звуков при перелистывании и паузе.

3. **📌 Удобный плавающий виджет (HUD) прямо на странице Shorts:**
   - Стильная полупрозрачная панель в темной теме в верхнем правом углу.
   - Быстрые тумблеры включения/выключения автопрокрутки и голосовых команд.
   - Индикатор статуса микрофона (слушает / ожидает / выключен).
   - Живое отображение распознанной фразы на экране.
   - Кнопка сворачивания в компактную кнопку, чтобы не отвлекать от видео.

4. **⚙️ Всплывающее меню настроек (Popup):**
   - Настройка задержки переключения.
   - Выбор языка распознавания речи.
   - Включение/отключение звукового сигнала и виджета на странице.
   - Встроенный тест микрофона в один клик.

## 🚀 Установка расширения в браузер

Расширение работает в **Google Chrome**, **Яндекс.Браузере**, **Microsoft Edge**, **Brave**, **Opera** и любых других Chromium-браузерах.

### Пошаговая инструкция:

1. Откройте страницу расширений в вашем браузере:
   - В **Google Chrome**: перейдите по адресу `chrome://extensions/`
   - В **Яндекс.Браузере**: `browser://extensions/`
   - В **Microsoft Edge**: `edge://extensions/`
2. В правом верхнем углу включите переключатель **«Режим разработчика»** (Developer mode).
3. Нажмите кнопку **«Загрузить распакованное расширение»** (Load unpacked) в левом верхнем углу.
4. Выберите папку с этим проектом:
   `C:\Users\conne\Documents\AntiGravity\Game`
5. Расширение появится в списке и сразу станет активным! Закрепите иконку на панели расширений для быстрого доступа.

## 🎙️ Как включить микрофон для голосовых команд

1. Откройте любой шортс на [YouTube Shorts](https://www.youtube.com/shorts/).
2. В правом верхнем углу появится виджет расширения.
3. Если браузер еще не имеет разрешения на микрофон для сайта YouTube, в блоке микрофона будет надпись: **«Нажмите, чтобы включить микрофон»**.
4. Нажмите на этот блок — браузер покажет стандартный запрос: *"Разрешить youtube.com использовать микрофон?"* ➔ Нажмите **«Разрешить»**.
5. Индикатор станет зеленым (🟢 **«Слушаю...»**). Теперь вы можете отдавать голосовые команды!

## 🗣️ Словарь поддерживаемых голосовых команд

| Действие | Команды (произнесите любую) |
|---|---|
| **Следующее видео (скип)** | *"далее"*, *"дальше"*, *"следующее"*, *"пропустить"*, *"пропусти"*, *"скип"*, *"не понравилось"*, *"дизлайк"*, *"next"*, *"skip"* |
| **Предыдущее видео** | *"назад"*, *"обратно"*, *"предыдущее"*, *"верни"*, *"back"* |
| **Пауза** | *"пауза"*, *"стоп"*, *"останови"*, *"pause"*, *"stop"* |
| **Воспроизведение** | *"плей"*, *"играй"*, *"продолжить"*, *"старт"*, *"play"* |
| **Поставить лайк** | *"лайк"*, *"нравится"*, *"класс"*, *"like"* |
| **Смотреть заново** | *"заново"*, *"повтор"*, *"повтори"*, *"еще раз"*, *"replay"* |
